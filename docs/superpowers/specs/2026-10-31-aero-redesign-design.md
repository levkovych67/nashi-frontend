# Редизайн НАШІ у Frutiger Aero

Дата: 2026-10-31. Основа — енциклопедія `~/development/encyclopedia/aero/` (особливо розділ 11 «Переклад на веб») і
вже налаштовані рецепти Радіо Цибулі (`~/development/radio-zubylia/src/aero/base.css`). Власник надиктував: «вивчи
енциклопедію, склади спеку й план, якісно перенеси дизайн Aero на НАШІ й імплементуй»; на запитання відповів «роби».

## 1. Мета

Увесь фронтенд НАШІ у Frutiger Aero (≈2004–2013): денне небо зі сяйвом, пагорбом трави й бульбашками; біле скло;
глянцеві «гелеві» кнопки; гуманістичний шрифт; техно-оптимізм. Карта України — світла, з блакитною водою й свіжою
зеленню. Людина, що пам'ятає Windows 7 і веб 2.0, впізнає епоху з першого погляду.

Успіх: перший екран (карта) читається як Aero; контраст тексту ≥ 4,5 : 1; працює від 390 до 1440+ px, на iPhone
Safari; `prefers-reduced-motion` і `prefers-reduced-transparency` поважаються.

## 2. Рішення (мої, власник може змінити)

| Питання | Рішення |
|---|---|
| Тема чи заміна | Повна заміна «Heritage Modern» (не тіньова тема, як у Цибулі) |
| Темна тема | Прибираємо: Aero — денний стиль. Перемикач у шапці зникає, `useThemeStore` спрощується до світлого |
| Шрифти | Прибрати Google Fonts (Playfair, Inter, Space Grotesk). Стек: `"Segoe UI", "Frutiger", "Frutiger Linotype", "Avenir Next", Avenir, "Lucida Grande", "Noto Sans", "Open Sans", Roboto, sans-serif` |
| Карта | Лишаємо MapTiler (`dataviz-light` чи `basic-v2`, ключ працює з localhost) і на `load` перефарбовуємо шари: вода — аква, суходіл — світлий, парки — трава. Контур України (`ukraineBorderStyle.ts`, зараз не підключений) — синя лінія зі світінням |
| Деплой | Гілка `aero-redesign`, без пушу в `main` (пуш = прод) до перегляду власником |
| Перевірка | Перевіряти на тимчасовому mock API за `swagger.json`, а не на бекенді |

## 3. Токени

Значення з розд. 11 енциклопедії: небо `#1f6fc5 → #4fa3e8 → #9ad4f7 → #e8f7ff`; аква `#00a2e8` / `#0a6cc2`; трава
`#5fbf2a` / `#2f8a10`; текст `#1e2b3c`, другорядний `#46586c`; заголовки `#003399`; посилання `#0066cc` (наведення
`#3399ff`); фокус 2 px `#0066cc` з відступом 2 px; біле скло `linear-gradient(rgba(255,255,255,.9), .74)` + `blur(12px)
saturate(150%)`; радіус 8 px (кнопки команд 3 px, гель — пігулка). Рух: світіння 0,3 с туди / 1 с назад; поява вікна
≈ 250 мс; бульбашки 12–30 с.

Змінні shadcn у `src/styles/globals.css` перепризначаються на ці токени (HSL): `--primary` = глибока аква,
`--accent` = синій посилань, `--card` = біле скло, `--border` = холодна блакитна, `--ring` = `#0066cc`.

## 4. Що на що

| Частина | Aero |
|---|---|
| Тло (`body`) | Два фіксовані шари: небо зі сяйвом і травою + плитка бульбашок, що рухається `transform`-ом |
| Шапка | Скляна смуга Aero зі смугами-відблисками 54°, кулька-логотип «Наші» зі світінням тексту, посилання — підсвітка наведення Windows 7 |
| Нижнє меню (мобільне) | Панель завдань Windows 7 (темне скло); кнопка «+» — кулька «Пуск» |
| Кнопки | `default` — аква-гель; «Додати / Надіслати» — трава-гель; `outline`/`secondary` — кнопка команди Windows 7; `ghost` — підсвітка списку; `destructive` — червоний гель |
| Картки (`Card`, артисти, події, новини) | Біле скло |
| Поля, select, textarea | Текстове поле Windows 7: біле, рамка `#abadb3`, наведення `#7eb4ea`, фокус `#569de5` |
| Sheet, Dialog | Вікно Windows 7 Aero: скляна рамка, білий вміст, червона «×» |
| Tabs, фільтри | Кнопки панелі команд / вибір у списку Windows 7 |
| Маркери карти | Артист — скляна кулька з аватаром; подія — трав'яний гель з іконкою lucide замість 🎭; лічильник стосу — аква-бульбашка |
| Завантаження, прогрес подання | Індикатор Windows 7 з бликом (цикл 3 с) |
| Радіоплеєр | Кругла глянцева кнопка Play, скляна панель керування |

## 5. Межі

Без нових npm-пакетів, шрифтів і картинок (лише CSS-градієнти й inline SVG). Жодних логотипів Windows/Microsoft.
`src/index.css` (залишок шаблону Vite) прибрати або нейтралізувати. Класи `dark:` (8 місць) прибрати.

## 6. Перевірка

`npm run type-check`, `npm run lint`, `npm run build`; знімки 390 і 1440 px усіх сторінок на mock API; перевірка
контрасту ключових пар кольорів; рев'ю гілки свіжим агентом перед показом власнику.
